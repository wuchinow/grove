# Peter's scenes (stand-in)

From Peter's Grove prototype. Provenance unconfirmed. Branch `redesign` only; never merge to `main`.

- `meadow-empty.png`: Peter's single-sapling meadow with the sapling painted out (GPT Image 2.5 edit via CreateSpace, Oct 2). The base plate for build 3's anchors.
- `meadow-first-seed.jpg`, `meadow-saplings.jpg`, `meadow-grown.jpg`: Peter's originals, trees baked in. Reference only.
- `meadow.webp`: `meadow-empty.png` as served, written by `scripts/cutout-trees.py`. The plate for landscape and desktop screens.
- `meadow-portrait.webp`: the same meadow repainted tall for phones held upright (rising uphill, the path winding up through it). Stand-in, provenance unconfirmed, like the rest of this folder. Written by `scripts/cutout-trees.py` from `narrow grove.png`, which is kept outside the repo.
