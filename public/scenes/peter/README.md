# Peter's scenes (stand-in)

From Peter's Grove prototype. Provenance unconfirmed. Branch `redesign` only; never merge to `main`.

- `meadow-empty.png`: Peter's single-sapling meadow with the sapling painted out (GPT Image 2.5 edit via CreateSpace, Oct 2). The base plate for build 3's anchors.
- `meadow-first-seed.jpg`, `meadow-saplings.jpg`, `meadow-grown.jpg`: Peter's originals, trees baked in. Reference only.
- `meadow.webp`: `meadow-empty.png` as served, written by `scripts/cutout-trees.py`. The plate for landscape and desktop screens.
- `meadow-portrait.webp`: the same meadow repainted tall for phones held upright, with one continuous path winding up through the middle of the grove (David's idea, Oct 3). Stand-in, provenance unconfirmed, like the rest of this folder. Written by `scripts/cutout-trees.py` from `~/Desktop/grove/narrow grove path.png`, which is kept outside the repo; the same run traces the path into `app/lib/scene-path.js`, which keeps trees off it. It replaced an earlier portrait plate (`narrow grove.png`) whose path ran to one side.

The working folder for Grove art is `~/Desktop/grove` (source paintings, and Peter's originals under `~/Desktop/grove/peter`). The copies in this folder are identical to Peter's originals.
